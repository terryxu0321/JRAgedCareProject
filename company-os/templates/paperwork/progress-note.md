# Progress Note / ADL Record — 模板

> **内部模板，非法律意见、非临床意见。** 复制后填写，不改本模板；不写真实居民信息。

| 项目 | 说明 |
|---|---|
| 用途 | 记录居民本班的观察、照护行动、居民原话与沟通对象；含 ADL（洗浴、穿衣、如厕、活动、进食饮水） |
| 何时使用 | 每班；居民状况有变化时（频率依机构政策【未核实】） |
| 谁填写 | PCW / AIN、EN、RN；PCW 记录按机构配置由 RN 复核 |
| 保存年限 | 7 年（Rules s 154 系列）；NSW / VIC / ACT 另有"最后一次服务后 7 年"，取较长 |
| 法规依据 | SQS 2.7、3.2；NMBA RN Standard 1.6、EN Standard 7；见 [paperwork checklist §2](../../03-legal-compliance/research/aged-care-paperwork-checklist.md)、[documentation workflows §3、§11](../../03-legal-compliance/research/aged-care-documentation-workflows.md) |
| CareKind | ✅ 口述 → 草稿 → 🛑 护理人员审核签字后才进入记录；正式记录库是机构护理系统 |

## 2. Observation（客观描述）

> 只写看到、听到、做到的事实；用可观察描述，不用"不合作""difficult"等标签。居民原话加引号。

- Observed: 【例：居民 A 早餐吃了约一半，推开餐盘】
- Resident said: "【居民原话】"
- Care provided: 【照护行动】
- Outcome: 【结果】
