# Care Plan Review / Case Conference Notes — 模板

> **内部模板，非法律意见、非临床意见。** 复制后填写，不改本模板；不写真实居民信息。

| 项目 | 说明 |
|---|---|
| 用途 | 记录 care and services plan 复审或 case conference 的讨论、居民本人意见和商定的后续行动 |
| 何时使用 | 定期复审（机构常见每 3–6 个月，非法定【未核实】）；SQS 3.1.5 触发事件（需求 / 偏好变化、状况变化、incident、转院返回等） |
| 谁填写 | RN / CM 主导，与居民及 Supporter / SDM partnership（经居民同意） |
| 保存年限 | 7 年（Rules s 154 系列） |
| 法规依据 | SQS 3.1.2、3.1.4、3.1.5、3.4.2；Rules s 148-80；Statement of Rights（Act s 23）；见 [documentation workflows §5](../../03-legal-compliance/research/aged-care-documentation-workflows.md)、[paperwork checklist §4](../../03-legal-compliance/research/aged-care-paperwork-checklist.md)、[federal-law-summary §1.2、§1.3](../../03-legal-compliance/research/federal-law-summary.md) |
| CareKind | ✅ RN 口述的讨论要点和居民原话 → 会议记录草稿 → 🛑 RN 审核签字；❌ 不自动改写 care plan，不给护理目标或干预建议，不推断居民意愿 |
