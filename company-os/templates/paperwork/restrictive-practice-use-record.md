# Restrictive Practice Use & Monitoring Record — 模板

> **内部模板，非法律意见、非临床意见。** 复制后填写，不改本模板；不写真实居民信息。字段由 Clinical Lead 审定前仅作结构参考（PRD D-06）。

| 项目 | 说明 |
|---|---|
| 用途 | 每次使用限制性措施（chemical、environmental、mechanical、physical restraint、seclusion）后的使用与监测记录，汇入 Behaviour Support Plan（BSP）use log |
| 何时使用 | 每次使用时 / 使用期间监测；紧急使用后尽快 |
| 谁填写 | RN / EN（PCW 可提供观察描述） |
| 保存年限 | 7 年（Rules s 154 系列） |
| 法规依据 | Rules s 162-30（监测）、s 162-35（紧急使用）、s 162-60（使用记录要素）、s 162-45 ~ 162-75（BSP）；Rules s 6-20（RPSDM）；见 [federal-law-summary §1.6](../../03-legal-compliance/research/federal-law-summary.md)、[documentation workflows §6](../../03-legal-compliance/research/aged-care-documentation-workflows.md)、[state-by-state-comparison §4](../../03-legal-compliance/research/state-by-state-comparison.md) |
| CareKind | ✅ 护士口述 → 使用记录草稿（字段对齐 s 162-60）→ 🛑 审核签字；❌ 不建议措施、药物、剂量或替代策略；不判定是否合规或须上报；同意状态只读 |

> 下列 s 162-60 要素按本地研究文件的描述整理（开始时间、持续时间、频率、结果、是否符合同意、参与人员、监测与复审）；法定字段的准确表述【未核实】。

| Field | Entry |
