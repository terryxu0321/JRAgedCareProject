# 招聘、入职与离职 Hiring, Onboarding & Offboarding

> Owner: CEO ｜ 复审: 每年 ｜ ⚠️ 雇佣合同模板须律师审阅；薪资与 Award 判定可咨询 Fair Work Ombudsman

## 1. 雇佣类型

| 类型 | 说明 | 注意 |
|---|---|---|
| 全职 / 兼职（permanent） | 享受 NES 全部权利 | 书面合同 |
| 临时工（casual） | 无带薪年假/病假，有 casual loading | 须提供 Casual Employment Information Statement；注意 casual conversion / "employee choice" 规则 |
| 独立承包商 | 按服务付费 | **警惕虚假承包（sham contracting）**—— 按 Fair Work Act 的"整体关系"测试判定；不确定就雇为员工 |
| 实习 | 无薪实习限制严格 | 仅限学历要求的 vocational placement；其他实习付薪 |

## 2. 雇佣合规清单（每位新员工）

- [ ] 书面雇佣合同：职位、薪资、适用 **Modern Award**（或 award-free）、工作时间、试用期、保密、**IP 归属公司**、通知期
- [ ] 判定适用 Award（如 Professional Employees Award 2020 / Clerks / Nurses Award 2020 —— 视职责而定；高收入且 award-free 情况另议）
- [ ] 提供 **Fair Work Information Statement**（及 casual / fixed-term 对应信息说明书）
- [ ] TFN declaration、Super choice form（未选择时：查询 ATO "stapled super fund"）
- [ ] 工资系统（STP）录入；**Payday Super**：SG 12% 随每次发薪缴纳，7 个工作日内到账；新员工首笔 20 个工作日内
- [ ] Workers compensation 保险覆盖（按州）
- [ ] 工作权利核验（签证持有人：VEVO 查询工作条件）
- [ ] **National Police Check**（所有可能接触居民数据或进入养老院的员工）；按客户要求的其他筛查
- [ ] 保密与可接受使用政策签署
- [ ] 隐私与信息安全培训完成
- [ ] 若进入养老院现场：疫苗/感染控制要求按机构政策

## 3. 招聘流程

1. 职位描述（JD）—— 不得含歧视性要求（Sex Discrimination Act、Age Discrimination Act、Disability Discrimination Act、Racial Discrimination Act 及州反歧视法）
2. 结构化面试 + 实际工作样例；评分标准提前确定
3. 背景调查与推荐人（经候选人同意）
4. Offer → 合同 → 入职

**多元化**：主动招募有 aged care 一线经验、CALD 背景的人才 —— 他们就是我们的用户。

## 4. 入职（第一周）

| 天 | 事项 |
|---|---|
| 第 1 天 | 设备（MDM、全盘加密）、账户 + MFA、阅读 Company OS README、价值观 |
| 第 2 天 | 隐私 + 安全培训；签署可接受使用政策 |
| 第 3 天 | 产品原则、临床安全框架、TGA 边界 |
| 第 4 天 | 听 3 段护士访谈录音（去标识化）/ 跟随一次客户会议 |
| 第 5 天 | 与 buddy 复盘；确定 30/60/90 天目标 |

## 5. 离职

- [ ] 当天收回全部系统访问、设备；轮换共享密钥
- [ ] 按 NES 结算：通知期、未休年假
- [ ] 提醒持续的保密与 IP 义务
- [ ] 离职面谈
- [ ] Separation certificate（如员工请求，按规定时限提供）
- [ ] 期权/股份按协议处理（good/bad leaver）

## 6. 员工记录

- 按 Fair Work Regulations 保存员工记录 **7 年**
- 员工记录在 Privacy Act 的"雇员记录豁免"范围内有特殊规则，但仍按公司标准保护
