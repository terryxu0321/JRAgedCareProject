# HR & Teams — CareKind AI

> Owner: Terry（直至有 People Lead）｜ 位置：`company-os/05-hr-teams/` ｜ 本文件夹存放组织架构、角色、招聘入职、员工政策，以及各团队的工作空间。

## 目录结构

```
company-os/05-hr-teams/
├── README.md                    ← 你在这里
├── team-roster.md               团队名册：Terry（Product Owner）、Ahmad / Matt / Dave（Developer）
├── team-members/                每位成员一个档案（terry / ahmad / matt / dave）
├── org-and-roles.md             组织架构、角色与职责（RACI）
├── hiring-and-onboarding.md     招聘、雇佣合规（Fair Work）、入职、离职
├── code-of-conduct.md           行为准则
├── people-policies.md           员工政策（工作时间、休假、远程、WHS、申诉等）
└── teams/
    ├── leadership/              创始人/管理层
    ├── engineering/             工程与 AI
    ├── clinical/                临床安全与护理顾问
    └── growth/                  市场、销售、客户成功
```

每个团队文件夹包含 `README.md`：团队使命、成员、职责、例会、当前重点。
