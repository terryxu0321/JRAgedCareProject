## 规则

- 每人一个文件，只记录**工作相关信息**：职位、职责、技能、负责领域、系统权限、入职进度
- **不记录**：薪酬、TFN、银行账户、住址、签证细节、病假/健康信息、背景调查结果 —— 这些放 HR/工资系统，严格限制访问
- 新成员加入：复制任一档案为模板，并在本表和团队名册各加一行
- 成员离职：档案移至 `alumni/`，在名册中标注离职日期，按[离职清单](../hiring-and-onboarding.md)收回权限
