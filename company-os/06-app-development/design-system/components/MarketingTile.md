# MarketingTile

营销网站的全宽区块：浅色与近黑交替，颜色变化本身就是分隔。只用于网站，不用于 App。

- `marketing-tile-light`：`canvas` 底、`ink` 文字；`marketing-tile-dark`：`surface-tile-1` 底、`on-dark` 文字。
- 上下内边距 `spacing-section`（80px），直角（`rounded-none`），区块之间无间隙。
- 内容居中：标题 `display-lg` → 一句副标题 `lead` → 最多两个胶囊按钮 → 一张图（`elevation-media` 投影）。
- 深色区块里的链接用 `primary-on-dark`；主按钮仍用 `primary` 填充。
- 图片只用授权的真实护理场景，不用真实居民照片；对外文案发布前走市场合规检查。
