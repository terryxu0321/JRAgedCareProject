# super-admin — Super Admin App

CareKind 平台方内部使用的**独立 React JS 应用**：管理多家养老院（租户）的开通、配置、机构管理员账号与去标识用量。**不接触居民健康信息。**

## 功能
- 养老院（租户）开通、编辑、停用（SA-01）
- 每家养老院的功能与配置（SA-02）
- 机构管理员邀请与停用、平台账号 MFA（SA-03）
- 去标识用量看板与平台审计日志（SA-04）

需求详见 [SPEC-010](../../specs/2026-10-super-admin-console.md)。
