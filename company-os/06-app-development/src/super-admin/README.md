# super-admin — Super Admin App

CareKind 平台方内部使用的**独立 React JS 应用**：管理客户公司（租户）的开通、配置上限、公司管理员账号与去标识用量。公司下的养老院、员工、老人由客户在养老院管理端维护（`admin-web/`）。**不接触居民健康信息。**

## 功能
- 公司（租户）开通、编辑、停用；只读查看其养老院与上线状态（SA-01）
- 每家公司的功能与配置上限（SA-02）
- 公司管理员邀请与停用（SA-03）
- 去标识用量看板与平台审计日志（SA-04）
