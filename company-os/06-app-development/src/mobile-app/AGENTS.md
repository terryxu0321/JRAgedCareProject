# AGENTS.md — mobile-app — 护理人员 App

> AI 助手在本目录工作前必读。全局规则：根目录 `AGENTS.md` 与 `company-os/11-rules/`。人类说明：同目录 `README.md`。完成任务后按 `changelog-rules.md` 写 `changelog/CHANGELOG.md`。

## 职责
护理人员手机/平板 App：开班选择负责老人、按键录音、离线加密队列、按老人分组的待审核与签字、老人时间线、交接摘要。只负责界面与采集，**不实现**归属/起草逻辑（属于 ai-pipeline，经 api 调用）。

## 负责的功能（PRD 编号）
- 开班与负责名单（PRD D2）
- 按键录音 R-01、离线加密缓存 R-02、班次会话 R-03、同意检查 R-04、挂绳设备 R-05、共享设备 R-06
- 待审核/编辑/签字 S-01–S-04、S-08
- 老人时间线 L-01–L-05（L-05 标注机构系统为正式记录库）
- 交接摘要 H-01

## 规则与边界
- 录音键响应 ≤ 100 ms，> 300 ms 不合格；冷启动 > 4 s 不合格（code-rules §11）
- 本地缓存必须加密，上传成功后删除；设备丢失可远程擦除
- 签字必须由人操作，**不存在**自动提交路径（F-5）
- 审核界面始终显示第二标识（房号/照片）；关键项逐项确认（S-03）
- 本地日志、崩溃报告不得含健康信息（P-1）
- 大按钮、单手操作、WCAG 2.2 AA

## 相关临床 hazard
- H-03 / H-09 错误老人
- H-06 故障丢失输入
- H-08 / H-11 自动化偏见与积压
- H-13 设备丢失

## 必须覆盖的测试
- 离线录音 → 恢复联网自动上传
- 签字前不可导出
- 关键项未确认不能签字
