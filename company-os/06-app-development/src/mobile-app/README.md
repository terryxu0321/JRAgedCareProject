# mobile-app — 护理人员 App

护理人员手机/平板 App：开班选择负责老人、按键录音、离线加密队列、按老人分组的待审核与签字、老人时间线、交接摘要。只负责界面与采集，**不实现**归属/起草逻辑（属于 ai-pipeline，经 api 调用）。

## 功能
- 开班与负责名单（PRD D2）
- 按键录音 R-01、离线加密缓存 R-02、班次会话 R-03、同意检查 R-04、挂绳设备 R-05、共享设备 R-06
- 待审核/编辑/签字 S-01–S-04、S-08
- 老人时间线 L-01–L-05（L-05 标注机构系统为正式记录库）
- 交接摘要 H-01
