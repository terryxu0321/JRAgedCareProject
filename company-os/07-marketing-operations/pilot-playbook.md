# 试点手册 Pilot Playbook

> Owner: CEO + Clinical Lead ｜ 每个试点复制一份到 `pilots/客户代号/`（客户名用代号）

## 试点设计（6–8 周）

| 周 | 活动 |
|---|---|
| -2 – 0 | 签署试点协议 + DPA；隐私/安全审查；确定试点单元（1 个机构/1 个病区）；**录音同意流程到位**；基线测量 |
| 1 | 现场培训（每个班次），超级用户（champion）指定 |
| 2–6 | 使用 + 每周与 DON 复盘 + 每周临床安全评审 |
| 7 | 结束测量、护士问卷、临床抽样审阅 |
| 8 | 结果报告与决策会 |

## 成功标准（试点开始前与客户书面约定）

| 指标 | 测量方法 | 目标（示例） |
|---|---|---|
| 每份 progress note 平均耗时 | 基线计时 vs 试点系统日志 | 下降 ≥ 40% |
| 记录完整性 | Clinical Lead + 客户临床经理按清单抽样 | 不低于基线 |
| 临床安全事件 | 事件登记 | 0 起高严重度 |
| 护士满意度 | 问卷（NPS/SUS） | SUS ≥ 70 |
| 周活跃使用率 | 系统日志 | ≥ 70% 受训员工 |

## 现场注意

- 进入养老院的员工：police check、按机构要求的疫苗与感染控制、着装与身份牌
- 不在走廊/公共区域讨论居民
- 不拍摄居民；不在个人设备存储任何资料
- 任何异常 → 当天报告 Clinical Lead

## 试点结束

- 无论是否转化：按 DPA 处理数据（删除或继续）
- 写结果报告（脱敏后可作为案例，需客户书面同意）
