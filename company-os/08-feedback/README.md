# Feedback — 用户反馈原始记录

> Owner: Terry ｜ 这里是**原始数据（raw）**：用户（护士、护理员、DON、客户）的原话与反馈，**由人工记录，不经过 AI 编写、改写、总结或翻译**。

## 规则

1. **原话照录**：用户怎么说就怎么写（包括语法错误、口语、非英语原文）。不润色、不总结、不翻译。
2. **不经过 AI**：`raw/` 内的文件只能由人手动录入（手打、或粘贴用户亲自写的文字，如邮件/表单原文）。不用 AI 生成、改写、补全。
3. **一条反馈一个文件**，录入后**不再修改**原话部分；补充说明写在"记录人备注"里，并注明日期。
4. **去标识化（人工完成）**：居民的姓名、房号、出生日期、病历号等**不得写入**；用 `[居民]`、`[房号]` 替代。用户本人姓名可用角色或代号（如 `RN-A`）。这是隐私法要求，不属于"改写"。
5. **分析与汇总放在别处**（如 `07-marketing-operations/` 或 `06-app-development/specs/`），引用这里的文件名 —— 不在 `raw/` 里写分析。
6. 附件（用户自己发来的截图、手写记录照片等，已人工确认无居民可识别信息）放 `attachments/`，文件名与反馈编号对应。

## 文件命名

`raw/YYYY-MM-DD_来源_编号.md`，例如 `raw/2026-10-14_interview_001.md`

来源：`interview`（访谈）· `pilot`（试点）· `email` · `form`（表单）· `call`（电话）· `onsite`（现场）· `support`（支持工单）

## 模板（复制后填写）

```markdown
# FB-编号

- 日期：
- 来源：interview / pilot / email / form / call / onsite / support
- 反馈人角色：RN / EN / PCW / AIN / DON / 临床经理 / IT / 其他
- 机构代号：
- 记录人：

## 原话（逐字，不改写）


## 记录人备注（可选，注明日期）

```
