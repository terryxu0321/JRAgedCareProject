# 术语表 Glossary

> Owner: 全员 ｜ 遇到新术语直接补充

## 养老行业

| 术语 | 含义 |
|---|---|
| **Aged Care Act 2024** | 新养老法，2025-11-01 生效，取代 1997 年旧法，建立以权利为本的体系 |
| **Statement of Rights** | 新法下可执行的长者权利声明（自主、尊严、隐私、信息、沟通等） |
| **Strengthened Aged Care Quality Standards** | 强化版质量标准（7 项标准），通过 Aged Care Rules 2025 成为注册提供者的法定义务 |
| **ACQSC** | Aged Care Quality and Safety Commission，养老质量与安全委员会（监管机构） |
| **Registered provider** | 新法下的注册养老服务提供者 —— 我们的客户 |
| **Care recipient / Resident** | 接受养老服务的长者（入住机构的称 resident） |
| **Support at Home** | 2025-11 起的居家养老项目（取代 Home Care Packages） |
| **AN-ACC** | Australian National Aged Care Classification，机构养老的资助分类模型 |
| **SIRS** | Serious Incident Response Scheme，严重事件上报机制（Priority 1 须 24 小时内上报） |
| **QI Program** | National Aged Care Mandatory Quality Indicator Program，强制质量指标 |
| **Care minutes / 24/7 RN** | 护理分钟数与 24 小时注册护士在岗要求 |
| **Restrictive practices** | 限制性措施（化学/物理/环境约束等），记录要求严格 |
| **Progress notes** | 护理进展记录 |
| **ADL** | Activities of Daily Living，日常生活活动 |
| **Handover** | 交接班 |
| **RN / EN / PCW / AIN** | 注册护士 / 登记护士 / 个人护理员 / 护理助理 |
| **CALD** | Culturally and Linguistically Diverse，文化和语言多元背景 |
| **Supported decision-maker** | 新法下的支持决策人（协助长者做决定，影响"同意"流程） |

## 法律与合规

| 术语 | 含义 |
|---|---|
| **Privacy Act 1988 / APPs** | 联邦隐私法及 13 条澳洲隐私原则 |
| **Sensitive information** | 敏感信息，含健康信息，收集需同意，标准更高 |
| **NDB scheme** | Notifiable Data Breaches，强制数据泄露通报机制 |
| **OAIC** | 澳洲信息专员办公室（隐私监管机构） |
| **APP 8** | 跨境披露规则 —— 数据出境时我们对接收方的行为负责 |
| **TGA / SaMD / ARTG** | 药品管理局 / 软件即医疗器械 / 澳洲治疗用品登记册 |
| **AHPRA / NMBA** | 卫生从业者监管局 / 护理与助产委员会 |
| **Surveillance / Listening Devices Acts** | 各州监听/录音法，规定录音需谁同意 |
| **Essential Eight** | ACSC 发布的 8 项网络安全基线措施 |
| **ACL** | Australian Consumer Law，消费者法（含虚假宣传、不公平合同条款） |
| **Fair Work Act / NES** | 劳动法 / 国家就业标准 |
| **SG / Payday Super** | 养老金保障（12%）/ 随薪发放养老金新规（2026-07-01 起） |
| **ESIC** | Early Stage Innovation Company，早期创新公司投资者税收优惠 |
| **RDTI** | Research and Development Tax Incentive，研发税收激励 |

## 公司内部

| 术语 | 含义 |
|---|---|
| **HITL** | Human-in-the-loop，人工审核环节（我们所有 AI 输出的强制要求） |
| **Clinical safety incident** | 可能影响居民安全的产品问题（见临床安全框架） |
| **DR** | Decision Record，决策记录 |
